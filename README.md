## 📖 О проекте

В условиях высокой конкуренции коммерческому блоку недостаточно просто искать клиентов — нужно системно анализировать инвестиционную активность и предлагать точные решения. 

**«Компас»** — это сквозной веб-сервис, который закрывает полный цикл B2B/B2G продажи: от поиска рыночной ниши до генерации готового коммерческого предложения. Система превращает массивы открытых данных (ФНС, реестры инвестиций) в понятные инструкции для менеджера: **Кого искать? Куда идти? Сколько просить?**

## 🚀 Три модуля — один цикл продажи

### 📡 1. Радар присутствия (Гео-аналитика)
* **Задача:** Визуализация плотности бизнеса и поиск «белых пятен».
* **Функционал:** Интерактивная тепловая карта (Leaflet.js) с кластеризацией. Фильтры по отрасли, выручке и динамике. Двухцветная индикация (наши клиенты / потенциал из ФНС).
* **Результат:** Экспорт отфильтрованных лидов в CSV для CRM.

### 🏗️ 2. Инвестиционный навигатор (Поиск проектов)
* **Задача:** Мониторинг капвложений и выход на клиента до этапа тендера.
* **Функционал:** Таймлайн инвестпроектов МО. Автоматическое определение стадии (Проектирование / Стройка / Запуск) на основе дат. Классификация потребностей (ИТ, АСУ ТП, Безопасность).
* **Результат:** Готовый список проектов с выявленной потребностью в телеком-решениях.

### 🧮 3. Калькулятор сделок (Экспресс-оценка)
* **Задача:** Устранение человеческого фактора при ценообразовании.
* **Функционал:** Расчет ценовой «вилки» (мин/оптимум/макс) с учетом региональных коэффициентов, срочности и состава работ. Дашборд маржинальности.
* **Результат:** Мгновенная генерация шаблона Коммерческого Предложения в формате `.doc`.

## 🛡️ Безопасность (Enterprise-уровень)

Система спроектирована с учетом строгих корпоративных стандартов:
* 🔐 **Двухфакторная аутентификация (2FA):** Реализован TOTP (RFC 6238), совместим с Google Authenticator / Яндекс.Ключ.
* 🛑 **Защита от брутфорса:** Блокировка аккаунта на 30 секунд после 5 неверных попыток ввода кода.
* 🔄 **Защита сессий:** Регенерация Session ID при входе, строгая изоляция.
* 🛡️ **CSRF-токены** во всех формах, хэширование паролей через `bcrypt`.
* 📁 **Изоляция данных:** Каталог `data/` закрыт от прямого доступа извне (Document Root — только `public/`).

## 🏗️ Архитектура и Масштабируемость

Проект написан по принципам **SOLID**. Слой работы с данными (`src/data.php`) полностью абстрагирован от UI и бизнес-логики. 

* **Сейчас (Прототип):** Чтение из `CSV` и `JSON` для максимальной скорости разработки и деплоя.
* **В продакшене:** Без изменения ни одной строчки в интерфейсе можно подключить `PostgreSQL` или `ClickHouse`.
* **Тиражирование:** Чтобы подключить новый регион (например, Краснодарский край), администратору достаточно загрузить 3 файла: реестр РСМП, справочник ОКВЭД и локальный прайс.
